## Objetivo

Meu foco é desenvolver interfaces e aplicações web responsivas, organizadas em componentes e voltadas para problemas reais de negócios e usuários.

No portfólio, apresento projetos institucionais e aplicações com funcionalidades como formulários, navegação por rotas, persistência local, geração de documentos e integrações.

## Executando localmente

```bash
git clone https://github.com/Jhonata7/meu-portifolio-dev.git
cd meu-portifolio-dev
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
